# GroupUp-
GroupUp! is a study group finder app for college students.
This is a repository with both frontend code and backend code as well as sql scripts to run on hosting machines.

# Hosting Use
To run, download XAMPP, then put /groupup into XAMPP/htdocs.
Run the XAMPP control panel in administrator mode \(Windows 11\), then run the sql scripts on the MySQL server.
from then go to localhost/groupup in your browser to interact with a run website locally.

# Visiting Use
To use this website as a client, connect with a hosting server.
